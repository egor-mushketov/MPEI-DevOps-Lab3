# Лабораторная работа №3 — Московская афиша (Геопоиск событий)

Веб-приложение для поиска культурных мероприятий Москвы в радиусе `N` метров от выбранной географической точки (**Индивидуальное задание: Задача 2**).

## Архитектура решения

Проект разворачивается в изолированной сети Docker Compose и состоит из трёх контейнеров:

| Сервис | Образ | Назначение | Внутренний порт |
| :--- | :--- | :--- | :--- |
| `db` | `postgis/postgis:17-3.6` | СУБД PostgreSQL 17 с расширением PostGIS 3.6 для геопространственных вычислений (`ST_DWithin`, `ST_Distance`) | `5432` |
| `backend` | `ghcr.io/nelkor/moscow-events:latest` | REST API сервер на FastAPI. При старте автоматически выполняет миграцию схемы `2026_01` и заполняет БД демо-набором (`SEED_MODE=sample`) | `8000` |
| `nginx` | `nginx:stable-alpine` | Веб-сервер для раздачи статики фронтенда (`/usr/share/nginx/html`) и reverse proxy для маршрутов `/api/`, `/docs`, `/redoc`, `/openapi.json`, `/health` | `80` (хост: `8080`) |

Данные базы данных сохраняются в именованном томе `pg_data` (`/var/lib/postgresql/data`) и не теряются при перезапуске или пересоздании контейнеров. Порядок запуска строго синхронизирован через `depends_on` с условием `condition: service_healthy`.

## Требования

* Установленный **Docker** и плагин **Docker Compose v2**.
